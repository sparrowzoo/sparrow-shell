Thymeleaf + Spring 语法对照

本页用于验证 Thymeleaf 集成 Spring 后，表达式引擎由 OGNL 切换为 Spring EL（SpEL） 的语法差异， 并对常用写法（取值、空值保护、HTML5 兼容、内联、去标签、URL 拼接）做等价对照。

2. HTML5 兼容写法

data-th-text="${user.userId}" data-th-remove="tag"

以 data- 前缀书写，保证模板通过 HTML5 校验，同时只输出内容不输出标签：


3. OGNL 与 SpEL 对照

引擎 写法 说明
原生 OGNL（旧） ${user?user.userId:''} 三元空值判断，集成 Spring 后不再推荐
Spring EL（现） ${user?.userId} 安全导航符，语义等价且更简洁

4. 三种渲染方式

方法 1：th:block

<th:block th:text="${user.userId}"/>

块级占位，不产生额外标签：

方法 2：inline 内联

[[${user.userId}]]      -- 不转义
[(${html})]             -- HTML 转义
  • 不会 HTML 转义：[[${user.userId}]]
  • HTML 转义（原始输出）：[(${html})]

参考：Inlining 章节

6. 获取请求 Query String（request.getQueryString()）

<script th:inline="javascript">
    var queryString = /*[[${queryString}]]*/ '';
    console.log("queryString: " + queryString);
</script>

Spring Boot 3.0（Thymeleaf 3.1）出于安全考虑已移除模板中直接访问 Servlet API 的表达式对象， #request / #httpServletRequest 在模板里均为 null， 直接调用会抛 EL1011E: Method call ... on null context object。 正确做法：由控制器或全局过滤器 request.setAttribute("queryString", request.getQueryString()) 放进 model，模板里用内联 [[${queryString}]] 直接读入 JS，无需 th:text 标签输出。
